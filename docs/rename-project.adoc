= rename-project.py — Project Rename Script
:toc: left
:toclevels: 2
:source-highlighter: highlight.js

== Purpose

One-shot script that rebrands the entire template to a new project identity.
It replaces two token pairs across every tracked file and moves the Java package directory.

[cols="1,2,2"]
|===
|Token |Replaced by |Scope

|`com.template`
|`--package` value (e.g. `com.acme.billing`)
|Java package declarations, Gradle group, all imports

|`spring-boot-template`
|`--name` value (e.g. `billing-service`)
|`rootProject.name`, `spring.application.name` default, `KEYCLOAK_REALM` default, Docker service/db/network/volume names, Keycloak realm name and SPA client ID
|===

== Prerequisites

* Python 3 (stdlib only — no pip install needed)
* Git (used for `ls-files` and `mv`; falls back to filesystem walk and `shutil.move` outside a repo)
* Run from a *clean working tree* so the rename stays fully reversible via `git reset --hard`

== Usage

[source,sh]
----
# Linux / Mac — preview (writes nothing)
python3 scripts/rename-project.py --package com.acme.billing --name billing-service --dry-run

# Linux / Mac — apply
python3 scripts/rename-project.py --package com.acme.billing --name billing-service
----

[source,powershell]
----
# Windows — preview (writes nothing)
python scripts\rename-project.py --package com.acme.billing --name billing-service --dry-run

# Windows — apply
python scripts\rename-project.py --package com.acme.billing --name billing-service
----

== Options

[cols="1,1,3"]
|===
|Option |Required |Description

|`--package PKG`
|Yes
|New Java base package. Lower-case dotted notation (e.g. `com.acme.billing`). Also becomes the Gradle group.

|`--name NAME`
|Yes
|New artifact/app name. Lower-case kebab-case (e.g. `billing-service`).

|`--dry-run`
|No
|Lists every file that would be edited and both package dir moves. Writes nothing.

|`--yes`
|No
|Skips the `[y/N]` confirmation prompt. Useful in CI pipelines.
|===

== Execution Flow

image::activity-rename-project.puml[Rename script execution flow]

The script runs five sequential stages:

. *CLI* — parses and validates `--package` and `--name`; rejects upper-case, invalid formats, and no-op invocations.
. *Filesystem discovery* — locates the repo root via `git rev-parse`; asserts `settings.gradle.kts` and the `com/template` package dir exist (guards against double-rename).
. *Content replacement* — reads each tracked file as bytes, decodes UTF-8, replaces both tokens in a single pass, and writes back only when content changed. Line endings (CRLF / LF) are preserved.
. *Package move* — moves `src/main/java/com/template` and `src/test/java/com/template` via `git mv` so the rename appears in git history as a rename, not a delete+add.
. *Cleanup* — removes empty parent directories left behind after the move.

=== File scope

[cols="1,1"]
|===
|Included |Excluded

|All files tracked by git (`git ls-files`)
|`build/`, `.gradle/`, `logs/`, `.idea/`

|`.env` (local, untracked)
|Binary files (UTF-8 decode failure)

|`realm-export.json` (realm name + SPA client ID)
|`scripts/rename-project.py` itself
|===

== Post-Rename Steps

[source,sh]
----
# 1. Inspect what changed
git diff

# 2. Verify the build compiles and tests pass
./gradlew build

# 3. Remove this one-shot script
rm scripts/rename-project.py          # Linux/Mac
del scripts\rename-project.py         # Windows

# 4. Commit
git add -A
git commit -m "chore: rename template to <your-project-name>"
----

== Notes

* The script guards against being run twice: if `src/main/java/com/template` no longer exists it exits with an error.
* `realm-export.json` contains the realm name *and* the Keycloak SPA client ID — both are `spring-boot-template` and both get replaced in the same pass.
* The `KEYCLOAK_REALM` env var in `.env` and `.env.example` drives the runtime; `realm-export.json` is the canonical source for the Keycloak import at container startup.
